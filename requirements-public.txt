# Dependencies for the PUBLIC service only (public/, served by Dockerfile).

# Deliberately not requirements.txt. That file installs streamlit, torch,
# transformers, faiss and sentence-transformers for the internal tool — none of
# which the public app imports. A public image should not carry code it cannot
# run: it is a larger attack surface, a slower pull, and a longer list of CVEs
# to answer for, all for capabilities the service does not have.
#
# Pinned exactly, like requirements.txt. `pip install -r` this into a fresh venv
# and the public app runs; anything it needs that is missing from here is a bug
# in this file, not a reason to fall back to the big one.
